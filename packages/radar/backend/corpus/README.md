# The consultable corpus

This is where `python -m app.jobs.export_corpus` writes, and what
[karajan-rag](https://karajancode.com/docs/karagan/) indexes. Nothing here is
generated by hand.

```
sources/     public    — what the publishers put out: title, abstract, identifiers
analysis/    internal  — what this radar concluded: themes, buckets, scores, summaries
quarantine/  not indexed
```

## Why the folders are the mechanism

karajan-rag resolves a document's sensitivity from its **path**, not its
contents: the indexer calls `sensitivityFor(relPath)` against `easy.sensitivity`
plus the prefix rules in `karajan.config.json`. **It does not read the
frontmatter.**

So the layout is not a filing convention. It is what decides whether a document
can travel to a public LLM when a question is answered. Moving a file between
these folders changes who can see it.

`sources/` is public because it already was — those abstracts were published
before this radar read them. `analysis/` is the organisation's reading of that
material, including why a paper matters *to this organisation*, which is a
statement about the organisation rather than about the paper.

## Why `quarantine/` is never indexed

Retrieval does not filter. `POST /query` returns every hit with its sensitivity
level, and the gate governs the LLM path (`/answer`: adapter routing and PII
redaction), not what comes back. **Everything indexed is servable.**

An item that tripped the ingestion injection scan would therefore reach an
agent as trusted context — precisely the consumer that scan exists to protect.
Items are held here rather than deleted: a paper that merely *discusses* prompt
injection trips the same patterns without being an attack, so the point is to
keep it out of the index, not out of existence.

## Wiring it up

```sh
python -m app.jobs.export_corpus ./corpus     # or set RADAR_CORPUS_DIR
karajan-rag index ./corpus
karajan-rag serve ./corpus                    # MCP for agents
karajan-rag serve ./corpus --http --port 8080 # HTTP, playground at /
```

Re-running the export rewrites `sources/`, `analysis/` and `quarantine/` from
empty, and leaves everything else in this directory alone — including this
file, `karajan.config.json`, and whatever karajan-rag stores when it indexes.
Then re-run `karajan-rag index`, which is incremental.
