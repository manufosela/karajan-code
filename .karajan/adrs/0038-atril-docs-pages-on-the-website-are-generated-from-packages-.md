# atril docs pages on the website are generated from packages/atril/README.md

Status: accepted
Date: 2026-10-28

## Context

HU-2750 adds an atril section to the docs site (overview, standalone, with the family). kaRAGan and Watch pages are generated by sync-family-docs from their repos pinned to a tag; atril lives in this monorepo and has no tag yet.

## Decision

Add atril to family-docs.config.mjs as a source split by its ## headings, pinned to the commit (or atril tag) of the release; the 'with the family' page is written by hand because it describes kj, not atril. English is the source; the Spanish pages are translations.

## Consequences

One source of truth and no drift, at the cost of keeping README sections page-shaped and re-running the sync on each atril release. The sync script may need to accept an English source with a Spanish translation dir (today the sources are Spanish).
